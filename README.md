# Calculadora Inteligente

Calculadora com três modos (básica, científica e conversor de moedas) e um assistente local que interpreta pedidos como "quanto é 15% de 320".

## Funcionalidades
- Calculadora básica e científica, com histórico
- Conversor de moedas com taxas actualizadas (Frankfurter API)
- Assistente que explica o raciocínio passo a passo
- Avaliador de expressões próprio, sem eval()

## Tecnologias
HTML, CSS e JavaScript puro.

## Como usar
Abre o `index.html` no navegador.
